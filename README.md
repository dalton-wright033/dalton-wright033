# Dalton Wright

Cybersecurity student and practitioner focused on understanding how systems are built, secured, and exploited.

My work spans network infrastructure, systems administration, penetration testing, security research, and security automation. I build and expand controlled environments to explore real-world security concepts, investigate attack paths, and document technical findings.

My interests include adversarial security, threat intelligence, network defense, and the intersection of offensive research and defensive engineering.

I believe effective security requires understanding both sides of the problem: how systems are designed to operate and how they can be abused when assumptions fail. My projects reflect that philosophy through practical lab work, technical documentation, and tools designed to improve security analysis.

## Technical Focus

- **Network Engineering:** Network architecture, VLAN segmentation, routing, switching, and firewall configuration.
- **Systems and Identity:** Windows Server, Active Directory, Group Policy, authentication, and access control.
- **Offensive Security:** Reconnaissance, enumeration, vulnerability analysis, exploitation, and privilege escalation.
- **Security Operations:** Log analysis, security event classification, detection engineering concepts, and digital forensics.
- **Security Research and Automation:** Python tooling, scripting, technical analysis, and reproducible security experiments.
- **Cloud Security:** AWS infrastructure, identity and access management, and cloud networking.
